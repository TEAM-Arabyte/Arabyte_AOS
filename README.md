## Tech Stack

| Title                  | Content                                                                 |
|------------------------|-------------------------------------------------------------------------|
| **Architecture**       | Clean Architecture, MVI, Single Activity Architecture                   |
| **Design Pattern**     | Repository Pattern                                |
| **UI**                 | Jetpack Compose                                                         |
| **Jetpack Components** | Lifecycle, ViewModel, Navigation            |
| **Dependency Injection** | Hilt                                                                  |
| **Network**            | Retrofit, OkHttp                                             |
| **Asynchronous Processing** | Coroutine                                                          |
| **Third Party Library**| Coil, Firebase, Timber, kotlinSerialization, Lottie, Kakao |
| **Strategy**           | Git Flow                                                                |

| **Other Tool**         | Notion, Figma, Postman, Discord                                  |
